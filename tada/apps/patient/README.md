# @tada/patient

Patient mobile app — Expo + React Native + NativeWind + expo-router.

This currently ships the **prototype demo shell**: a role picker home, then the
patient flow up to the phone-number entry screen. Real auth (OTP via Hubtel)
lands in Module 4.

## Screens

| Route          | Purpose                                                                  |
| -------------- | ------------------------------------------------------------------------ |
| `/`            | Role picker (Patient / Driver / Operator / Hospital). Non-patient roles show a "coming soon" alert. |
| `/splash`      | Red TADA splash. Auto-redirects to `/onboarding` after 1.5 s.            |
| `/onboarding`  | 4-slide carousel (Emergency / Rapid response / Real-time tracking / Safe & Secure). |
| `/login`       | "Welcome to TADA" + phone-number entry. `Send Code` is currently a no-op (wired in Module 4). |

Tap **Patient** on `/` to walk through `/splash → /onboarding → /login`.

## Run it

From the **repo root** (where `pnpm-workspace.yaml` lives, i.e. `tada/`):

```bash
pnpm install                 # first time only
pnpm --filter @tada/patient dev    # or: cd apps/patient && pnpm dev
```

Then choose how you want to view it:

- **Web** — open <http://localhost:8081> (or press `w` in the Expo CLI prompt).
- **iOS sim / Android emulator** — press `i` or `a` in the Expo CLI prompt.
- **Physical device** — open Expo Go and scan the QR code shown in the terminal.

The Supabase env vars in `tada/.env` are not used by the current screens, so a
placeholder `.env` (copied from `.env.example`) is enough to boot.

## Architecture notes (only relevant if you touch config)

- **pnpm + Expo monorepo.** Requires `tada/.npmrc` with `shamefully-hoist=true`
  so React Native / Metro can resolve hoisted deps.
- **Entry shim.** `index.js` at the app root just does `import 'expo-router/entry'`.
  Without this, Expo emits a bundle URL that points into `.pnpm/...`, which
  doesn't exist under `apps/patient/node_modules/` and the page renders blank.
- **NativeWind.** `tailwind.config.js` sets `darkMode: 'class'` — required to
  silence a `react-native-css-interop` runtime error on web.
- **Metro.** `metro.config.js` enables `unstable_enableSymlinks` and
  `unstable_enablePackageExports` for pnpm's symlinked layout.

## Troubleshooting

- **Blank page on web.** Stop Metro, then
  `rm -rf .expo node_modules/.cache && pnpm dev --clear`. If still blank,
  confirm `tada/.npmrc` exists.
- **`expo-env.d.ts` keeps showing as modified in git.** It's auto-generated by
  expo-cli; `.gitignore` already excludes it.
- **TS version warning at startup.** Expo wants TS `~5.3.3`; the workspace has
  `^5.5.4`. The warning is cosmetic and can be ignored for now.
